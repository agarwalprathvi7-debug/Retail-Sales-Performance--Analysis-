# GitHub Upload Instructions

1. Sign in to GitHub and create a new repository named `Retail-Sales-Performance-Analysis`.
2. Keep the repository public if your trainer requires a public submission; otherwise follow the training instructions.
3. In VS Code, open the extracted project folder.
4. Open the terminal and run these commands one at a time:

```bash
git init
git add .
git commit -m "Add retail sales performance analysis project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Retail-Sales-Performance-Analysis.git
git push -u origin main
```

5. Replace `YOUR-USERNAME` with your GitHub username.
6. Refresh the repository page and confirm that `main.py`, `data`, `SRS`, and `outputs` are visible.

If Git asks you to authenticate, complete GitHub's browser sign-in flow or use an approved personal access token. Never paste a password or token into a public file.
